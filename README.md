# 烟雨江湖 · 观星模拟器（网页版）

烟雨江湖本地存档工具网页版：导入存档后，可在本地/网页端推演**洗髓、装备打造升炼、角色面板**等，不消耗游戏内材料。

## 在线使用

打开部署好的 GitHub Pages 网址（见仓库 About / Settings → Pages），点击首页「导入数据」，选择本地的 `dat.db` 存档文件即可。

存档文件由配套命令行工具生成：

    python run.py capture 抓包文件.har   # 从抓包导出
    python run.py local                  # 从模拟器存档导出

生成的文件位于 `output/平台-区服-用户名/日期时间/` 目录下的 `dat.db`。

## 模块

| 模块 | 功能 |
| --- | --- |
| 洗髓模拟 | 洗脉、锁脉、保底与置换推演 |
| 装备模拟 | 打造、升炼、精炼与淬炼 |
| 角色面板 | 角色、天赋、装备与属性 |
| 角色状态 | 永久培养进度、剩余量与属性上限 |
| 自动模拟 | 自动洗脉路线与装备批量预测 |

## 本地运行

直接双击 `index.html`，或在目录下起一个静态服务：

    python serve.py

## 说明

- 纯前端、不联网、存档只在本地浏览器内存中处理
- 基于游戏 APK 内置网页应用整份复制，仅供学习交流
